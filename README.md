This is a series of python functions that serve as a sort-of API to [mitsuba3](https://www.mitsuba-renderer.org/) The focus for this library is rending atomistic simulation data i.e. 3D coordinates of proteins/particles and the like. The idea is to use the power of Mitsuba in a distributed computing environment to create publication quality images. I will put up the docker soon 

Basically, it is so convenient to use mitsuba in jupyter format.
and this library serves as a simplier way to tweak parameters.

I named it Mitsume because: Mistu (honey) + Me (eyes) = mitsume (staring)
